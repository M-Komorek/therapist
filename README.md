# therapist

[![CI](https://github.com/M-Komorek/therapist/workflows/CI/badge.svg)](https://github.com/M-Komorek/therapist/actions)

therapist is a Rust TUI app for browsing large log files: vim-like motions, search, bookmarks with a side panel, cascading grep tabs and phrase highlighting.

## Status

MVP done: you can open a log file and browse it with vim motions.

## Usage

```bash
cargo run -- path/to/file.log
```
